# Bauer fork

Bauer fork. Bauer marketing starts at the `bauer-motion` skill in `bauer-automate/claude-skills`.
That skill asks a few intake questions and routes here only for data-driven videos, batch
rendering, and React-based work.

Remotion needs a paid Company License for companies with more than 3 employees; see bauer-motion-engine `references/tooling-choices.md`.

Keep this fork close to upstream. Bauer-specific guidance lives in claude-skills, not here.

Install from this fork, not from upstream: `npx skills add bauer-automate/3P-remotion`.
